# 들켰다.

AI가 내 선택을 미리 예측하는 한국어 웹게임. 약 1분 30초 동안 16개의 선택을 하고, 마지막에 예측을 펼쳐 봅니다.

[플레이하기](https://deulkyeotda-choice-game.jovialyew65.chatgpt.site/)

## 실행

Node.js 22.14 이상이 필요합니다. 외부 패키지 설치나 빌드 없이 실행합니다.

```sh
git clone https://github.com/hb188641/deulkyeotda.git
cd deulkyeotda
npm start
```

브라우저에서 <http://127.0.0.1:5087>을 엽니다. 키가 없으면 **규칙 기반 데모**로 동작합니다.

실제 AI를 사용하려면 `.env.example`을 `.env`로 복사하고, 본인의 `OPENAI_API_KEY`를 직접 입력합니다. 키는 서버에서만 사용하며 브라우저에 전달하지 않습니다. `GAME_SESSION_SECRET`에는 별도의 임의 비밀값을 넣을 수 있습니다. 기본 모델은 `gpt-4.1-mini`이며 `OPENAI_MODEL`로 변경합니다. 실제 AI 플레이는 본인 API 사용량에 청구됩니다.

```sh
cp .env.example .env
# .env를 편집한 뒤
npm start
```

`PORT`와 `HOST`로 실행 주소를 지정합니다. 저장소는 기본 `data/game.sqlite`이며 `DATABASE_PATH`로 변경할 수 있습니다. 서버 재시작 후에도 유지되므로 운영 시 이 파일을 백업하세요. 외부 공개 운영에는 HTTPS 프록시와 API 요청 제한을 별도로 구성하세요.

## 게임 흐름

- 미리 만든 질문 40개에서 준비 6개 + 예측 10개를 중복 없이 무작위 선정합니다.
- AI는 준비 답변 6개를 보고 나머지 10개의 예측을 **한 번의 요청**으로 작성합니다.
- 예측·확신도·질문 구성을 암호화해 실제 선택 전에 봉인합니다.
- 모든 선택 후 확신도가 높은 순서대로 공개합니다. 건너뛰기도 가능합니다.
- 적중 횟수, 승패, 최대 실수, 의외의 성공을 표시합니다.
- 친구 도전 링크는 같은 질문 구성을 사용하고, 결과를 이미지로 저장·공유할 수 있습니다.
- 모바일 우선의 반응형 화면입니다. 작은 화면이나 큰 글씨 설정에서는 내용이 잘리지 않도록 스크롤할 수 있습니다. 실제 플레이 시간은 선택 속도에 따라 달라집니다.

확신도는 모델의 자기 평가이며, 충분한 기록이 있으면 과거 적중률을 참고해 보정합니다. 검증된 개인 예측 확률이 아니며 성격·지능을 판단하지 않습니다.

## 익명 기록과 예측 개선

홈에서 **익명 답변으로 예측 개선에 참여**를 선택한 AI 판만 저장합니다. 처음 방문 시 기본 체크되며, 직접 해제한 선택은 유지합니다., 데모·미완료·미참여 판은 저장하지 않습니다. 참여하지 않은 판에서는 누적 통계도 사용하지 않습니다. 선택 여부만 브라우저에 보관합니다.

게임 기록에는 판마다 새 식별자, 질문 버전, 완료 시각, 준비 답변, 사전 예측·확신도·실제 답변, 비교군을 저장합니다. 이름·계정·IP·기기 식별자는 저장하지 않습니다. 같은 봉인 토큰의 재제출은 중복 집계하거나 최초 기록을 덮어쓰지 않습니다. 운영 환경 자체의 로그 정책과는 별개입니다.

예측은 최근 90일의 최신 1,000판을 참고합니다. 같은 준비 질문에서 같은 답을 2개 이상 골랐고 일치가 불일치보다 많은 기록을 우선합니다. 질문별 유사 기록 20개부터 참고하고, 부족하면 전체 기록 50개부터 참고합니다. 모델에는 집계된 선택 비율과 표본 수만 추가 전달합니다. 다른 플레이어의 개별 답변은 보내지 않습니다.

통계를 참고할 수 있는 참여 판 중 약 80%는 통계를 사용하고 20%는 기존 방식으로 예측합니다. 두 그룹의 사전 예측과 실제 적중을 비교하며, 각 그룹 20판·100예측 이상일 때 게임 안내에 관측 적중률을 표시합니다. **데이터 누적만으로 정확도 향상을 보장하거나 주장하지 않습니다.** AI 모델 가중치를 재학습하는 방식이 아닙니다.

동일한 원래 확신도 구간에 과거 통계 참고 판의 기록이 30예측 이상이면 표시 확신도를 보정합니다. 데이터 조회 실패 시 기존 AI 예측을 사용하고, 저장 실패 시 게임 결과와 함께 저장 실패를 알립니다. `/api/learning`은 집계만 반환하며 원본 답변 조회 API는 제공하지 않습니다.

## 소스 구조

| 경로 | 역할 |
| --- | --- |
| `index.html`, `public/` | 화면, 질문 목록, 선택·공유 흐름 |
| `lib/game/server.mjs` | API 요청 검증, AI 호출, 예측 봉인·결과 계산 |
| `lib/game/learning.mjs` | 유사 선택 통계, 확신도 보정, 익명 기록 |
| `scripts/server.mjs` | Node.js HTTP 서버와 SQLite 연결 |
| `db/`, `drizzle/` | 저장 스키마와 SQL 마이그레이션 |
| `tests/` | 봉인·무작위 선정·저장·참여 해제·서버 검사 |

질문 내용이나 선택지 의미를 변경하면 `lib/game/learning.mjs`의 `QUESTION_VERSION`도 올려 이전 기록과 섞이지 않도록 합니다. 현재 서버는 최초 실행 시 스키마 v1을 자동 생성합니다. 후속 스키마 변경에는 추가 마이그레이션 구현이 필요합니다.

## 검사

```sh
npm test
```

자동 검사는 가짜 모델 응답과 메모리 SQLite를 사용합니다. OpenAI를 호출하거나 API 비용을 발생시키지 않습니다.

배포된 Sites 게임의 프론트엔드와 예측·집계 로직을 가져오고, 공개 저장소에서는 Node.js/SQLite로 독립 실행하도록 구성했습니다. Sites 내부 배포 설정·인증 정보·운영 데이터는 포함하지 않습니다.
